# Contributing to github-final-project

Thank you for your interest in contributing! This guide explains how you can help.

## Reporting Issues

If you find a bug or have a suggestion:

1. Check the existing issues to make sure it hasn't already been reported.
2. Open a new issue with a clear title and a short description.
3. Include steps to reproduce the problem, if it's a bug.

## Making Changes

1. Fork this repository.
2. Create a new branch for your change:
   ```bash
   git checkout -b my-feature-branch
   ```
3. Make your changes and commit them with a clear message:
   ```bash
   git commit -m "Describe your change"
   ```
4. Push the branch to your fork:
   ```bash
   git push origin my-feature-branch
   ```
5. Open a pull request against the `main` branch and describe what you changed and why.

## Guidelines

- Keep changes small and focused on one thing.
- Test your changes (for example, run `simple-interest.sh` to make sure it still works).
- Be respectful to other contributors, as described in our [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions

If you're unsure about anything, open an issue and ask. We're happy to help.
